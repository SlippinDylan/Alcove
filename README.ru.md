## Что такое Alcove

Alcove показывает локальные папки в виде лёгких панелей на уровне рабочего стола. В каждой панели есть прокручиваемая сетка нативных значков, вкладки, выделение в стиле Finder, быстрый просмотр и восстановление расположения после изменения конфигурации дисплеев. Панели находятся под обычными окнами приложений, но над значками рабочего стола.

**Alcove не заменяет Finder.** Приложение даёт быстрый доступ к папкам, которые удобно постоянно держать на рабочем столе.

## Состояние проекта

> **Функции MVP реализованы**

Приложение, автоматические тесты и проверка сборки arm64 готовы. Перед первым публичным выпуском остаётся вручную проверить установку итогового DMG, поведение Gatekeeper, а также работу с несколькими дисплеями, Spaces и Stage Manager.

## Системные требования

| Параметр | Значение |
|---|---|
| Минимальная версия | macOS 26 Tahoe |
| Целевые версии | macOS 26 и macOS 27 Golden Gate |
| Процессор | Apple Silicon (arm64) |
| Тип приложения | Несандбоксированное приложение LSUIElement для строки меню, без значка в Dock |
| Поддерживаемые папки | Только локальные папки на встроенном несъёмном диске |
| Распространение | Один подписанный сертификатом Apple Development, но не нотариально заверенный DMG в GitHub Releases |

## Установка и выпуски

Каждый выпуск на GitHub содержит один файл `Alcove.<версия>.dmg`. Откройте DMG и перетащите `Alcove.app` в папку `Applications`. Выпуски подписываются бесплатным сертификатом Apple Development, но не проходят нотариальное заверение Apple. Перед первым запуском удалите атрибут карантина загрузки согласно примечаниям к выпуску:

```bash
sudo xattr -rd com.apple.quarantine /Applications/Alcove.app
```

Поддерживаются номера версий `x.y.z`, `x.y.z-alpha.n` и `x.y.z-beta.n`. Список изменений находится в [CHANGELOG.md](CHANGELOG.md).

## Основные решения

- Приложение написано на нативном AppKit без WidgetKit.
- Для панелей используется стабильный статический полупрозрачный фон, пять уровней прозрачности и отдельный цвет каждой панели.
- Выделение, быстрый просмотр, перетаскивание и контекстное меню повторяют привычное поведение Finder.
- Общие настройки внешнего вида и язык хранятся в `UserDefaults`, а расположение панелей — в версионируемом JSON-файле.
- В приложении нет телеметрии, аналитики и сетевых запросов. Все данные остаются на Mac.
